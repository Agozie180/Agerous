AI interpreter

Agerous understands plain language offline with built-in rules. Add your own key and an LLM interprets your prompts instead — but it can only emit events from a fixed schema, which are validated before the simulation runs them.

The key is stored only in this browser's localStorage and sent only to the provider you pick. For a public deployment put a small proxy in front instead (see README).
