AI interpreter

Agerous understands plain language offline with built-in rules. Add your own key — official or any third-party gateway with a base URL (OpenRouter, Groq, DeepSeek, Ollama, AgentRouter-style relays…) — and an LLM interprets your prompts instead — but it can only emit events from a fixed schema, which are validated before the simulation runs them.

The key is stored only in this browser's localStorage and sent only to the base URL you set. If a gateway blocks browsers (CORS) use the server proxy: set LLM_BASE_URL / LLM_API_KEY / LLM_MODEL on the server (see README).
